## process
i built this because i've always wanted to make a game console. I joined "make your own game console" back in march and like never started it, so this is kind of me reviving that. now that i think about it, this kind of looks like a sprig, except it has detachable controllers, joysticks, and connectors so that you can play it on the whole pcb or just seperate it- whatever works for you!
## how this works
you flash the firmware (located in firmware folder) to the chips- the xiao esp32c3 and the orpheus pico :3
once doing that, you can use the console to play a game by putting a chip into the tft display!
